# 📁 局域网文件共享服务器

一个简洁易用的Flask Web应用，支持在局域网内进行文件共享、上传和下载。

## ✨ 功能特性

- 📤 **拖拽上传**: 直接拖拽文件到网页上传
- ⬇️ **秒速下载**: 点击即可下载文件或文件夹（自动打包成zip）
- 📂 **文件管理**: 查看文件大小、修改时间，支持删除
- 🌐 **局域网访问**: 无需账号密码，直接用IP地址访问
- 🏷️ **域名访问（可选）**: 支持在局域网内通过自定义域名访问
- 🎨 **美观界面**: 现代化Web界面，支持移动设备
- 🔄 **实时更新**: 自动刷新文件列表

## 🚀 快速开始

### 方式一: 双击启动（推荐Windows用户）

1. **双击 `run.bat` 文件**
   - 第一次运行会自动安装依赖（需要网络连接）
   - 然后自动启动服务器

2. **看到以下输出说明启动成功:**
   ```
   🚀 文件共享服务器已启动!
   🧭 第一次运行请先在本机打开一次页面完成初始化
   📍 本地访问: http://127.0.0.1:5000
   🌐 网络访问: http://YOUR_IP:5000
   🏷️ 域名访问: http://YOUR_DOMAIN:5000 (可选)
   📁 文件上传/存储目录: D:\\SharedServer\\SharedFolder
   ```

### 方式二: 命令行启动

```bash
# 1. 安装依赖（仅第一次需要）
pip install -r requirements.txt

# 2. 启动服务器
python app.py
```

## 📱 客户端访问

### 在同一局域网的其他电脑上：

1. **打开浏览器**（任何浏览器都可以）
2. **输入地址**: `http://服务器IP:5000`
   - 例如: `http://192.168.1.100:5000`
   - 或在服务器启动时看到的 `🌐 网络访问` 地址

3. **即可使用:**
   - 📤 拖拽上传文件
   - ⬇️ 点击下载文件
   - 🗑️ 点击删除文件

## 🔧 配置说明

### 修改端口号

编辑 `app.py` 的最后一行，将 `5000` 改为其他端口：
```python
app.run(host='0.0.0.0', port=8080, debug=False, use_reloader=False)  # 改为8080
```

### 修改共享文件夹

默认共享的是脚本所在的文件夹 `d:\SharedServer`。
要修改共享文件夹，编辑 `app.py` 第13 行：
```python
UPLOAD_FOLDER = Path(__file__).parent / 'SharedFolder'  # 默认共享子目录 SharedFolder
UPLOAD_FOLDER = Path('D:/your/path')   # 示例
```

### 使用局域网域名访问（可选）

1. 在服务器端设置环境变量 `LAN_DOMAIN`（示例：`files.home`）
2. 在局域网 DNS 或每台客户端的 hosts 文件中，将该域名指向服务器 IP
3. 重启服务后可用 `http://files.home:5000` 访问

Windows 临时设置示例：
```bat
set LAN_DOMAIN=files.home
python app.py
```

### 修改最大文件大小

编辑 `app.py` 第14 行（默认10GB）：
```python
app.config['MAX_CONTENT_LENGTH'] = 10 * 1024 * 1024 * 1024  # 改为所需大小
```

## 🔒 安全性说明

- **无身份验证**: 局域网内任何人都可以访问
- **防止恶意删除**: 系统文件（app.py、requirements.txt）无法删除
- **防止目录遍历**: 防止访问指定文件夹外的文件
- **仅支持局域网**: 不支持从互联网访问

## 🐛 常见问题

### Q: 其他电脑无法访问？
A: 
- 确保双方在同一局域网
- 检查防火墙是否阻止5000端口
  - Windows：设置 > 防火墙 > 允许应用通过防火墙 > 允许Python

### Q: 上传总是失败？
A:
- 检查磁盘空间是否充足
- 检查文件夹权限

### Q: 能否从互联网访问？
A: 默认只支持局域网。要开放互联网访问，需要配置端口转发或使用ngrok等工具。

## 📊 文件大小支持

- 默认支持最高 **10GB** 单个文件
- 支持同时上传多个文件
- 文件夹下载时自动压缩为zip

## 🛑 停止服务

按 `Ctrl + C` 停止服务器
