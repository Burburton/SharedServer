# SharedServer 局域网文件传输

Flask 网页界面，Waitress 提供服务。支持多文件拖拽上传、浏览器下载、文件夹 ZIP 下载、删除和磁盘空间显示。

## 启动

需要 Python 3.10+（Linux 需安装对应的 python3-venv 组件）。

Linux / macOS：

```bash
./run.sh
```

Windows：双击 `run.bat`。

脚本会创建项目独立的 `.venv` 并安装依赖。首次启动在终端设置并确认固定密码（至少 6 个字符，输入不显示），之后重启自动沿用。账号始终是 `shared`，无需注册。终端会显示访问地址和二维码，手机扫码后输入账号和固定密码；浏览器可保存凭据。网页也可展开“手机扫码访问”。

密码以加盐哈希保存在项目内 `.sharedserver.json`，不会明文保存或提交到 Git。二维码仅包含地址，不包含密码。手机仍需能够访问服务器所在网络，扫码不能绕过 NAT。

忘记密码或需要修改时，停止服务并执行：

```bash
./run.sh --reset-password
```

Windows 在命令行执行 `run.bat --reset-password`。若配置了 `SHARED_PASSWORD`，登录始终优先使用该环境变量；要改用保存的密码，请先取消这个环境变量。

## 配置

通过环境变量配置，无需修改源码：

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| SHARED_FOLDER | 项目下 SharedFolder | 共享目录，支持绝对路径和 ~ |
| SHARED_PASSWORD | 未设置 | 可选：覆盖本地保存的密码，适合自动化部署 |
| HOST | 0.0.0.0 | 监听地址 |
| PORT | 5000 | 端口 |
| MAX_UPLOAD_BYTES | 10737418240 | 单次上传请求上限，包含 multipart 开销 |
| LAN_DOMAIN | 空 | 在界面显示的可选局域网域名，需自行配置 DNS |

例如共享桌面：

```bash
SHARED_FOLDER="$HOME/Desktop" PORT=5000 ./run.sh
```

共享目录内可见的文件与文件夹均可被已登录用户下载和删除，请选择实际需要共享的目录。HTTP Basic 认证用于可信局域网；跨公网使用时需在前方配置 HTTPS 和网络访问限制。

## 文件处理规则

- 同名上传自动保存为 `文件 (1).扩展名`，原文件保留；并发上传也不会覆盖。
- 上传先写隐藏临时文件，完成后原子发布；失败自动清理临时文件。批量上传中已经完成的文件会保留。
- 拒绝路径越界、符号链接和隐藏路径；文件夹打包时跳过隐藏文件和符号链接。
- 文件夹在系统临时目录打包，下载结束后释放，不在共享目录遗留 ZIP。打包需要额外磁盘空间，打包完成后浏览器开始接收。
- 普通文件直接由浏览器下载，支持 HTTP Range；进度和速度请查看浏览器下载列表。ZIP 暂不支持断点续传。
- 界面安全呈现文件名；写操作要求同源和专用请求头。
- 网页文件列表每 5 秒刷新；目录不递归统计大小，避免大型共享目录反复扫描。

## 验证

```bash
.venv/bin/python -m unittest -v
```

运行时请避免其他本地程序在请求期间替换共享目录中的路径或符号链接。本服务不是针对不可信本地用户的文件系统隔离工具。
